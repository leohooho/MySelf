# MySelf

个人配置与脚本的合集仓库，用于备份和同步各类日常使用的配置文件。

## 目录结构

```text
Egern/
├── Profile.yaml     Egern 手机端精简配置（分流规则）
└── Widget/
    └── Widgets.yaml 小组件配置
```

## Egern 配置

当前收录了 **Egern**（iOS 网络代理工具）的一套精简配置：

- **分流策略**：局域网 / Apple / 中国大陆直连，AIGC 独立手动选择，其余流量走代理（Proxy）
- **端口**：HTTP `3080`、SOCKS `3090`
- **直连规则**：局域网与保留地址（`10.0.0.0/8`、`192.168.0.0/16` 等）不进入隧道

### 使用方式

将 `Profile.yaml` 导入 Egern 应用，`Widget` 目录内的小组件配置按需启用即可。
